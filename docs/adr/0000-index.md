## 备注：关于“框架选型的场景决定论”

本项目在 0001 中选择了 Gradio，而开发者在随后的平行项目 `task-planner` 中选择了 Dash。
这并非技术栈的摇摆，而是因为：
- **DeepDream Agent 是“表单与生成”应用**，线性的“输入 → 等待 → 输出”闭环，Gradio 是最佳解。
- **Task Planner 是“看板与图操作”应用**，需要对 DAG 节点进行高密度的 DOM 交互，Dash + Cytoscape 才是正解。
